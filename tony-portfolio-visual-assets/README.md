# Tony Joy portfolio visual assets

Monochrome SVG line drawings intended for the portfolio wireframe:
- about-sitting.svg — About section
- microscope.svg — Work section
- building-blocks.svg — Open Source + WIP
- microphone.svg — Talks
- help-*.svg — Ways I can help
- footer-activities.svg — continuous footer activity line

Design intent:
- black/near-black strokes on transparent backgrounds
- simple editorial line-drawing language
- no fills or colour dependencies
- SVGs are deliberately lightweight and easy to recolour through CSS if needed
- use as supporting illustrations, not decorative wallpaper
